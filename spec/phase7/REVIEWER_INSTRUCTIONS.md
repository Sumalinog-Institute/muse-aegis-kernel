# Phase 7: instructions for independent reviewers

**What this is.** A test of how well an AI document-screening tool (MUSE Aegis) and a plain AI judge find real inconsistencies in GCF documents. Your labels are the independent ground truth. The author already labelled the same issues and will not show you those labels.

**Time.** About 8 to 10 hours in total, over about two weeks. Do it in sessions of up to two hours.

**Steps**
1. Read `LABELLING_GUIDE.md` once.
2. Do the practice issues if you received them, and read the author's practice answers.
3. Label all 69 issues. Work in order. Save the file often.
4. Return the file by email by the agreed date, named `reviewer_<your initials>_labels.csv`.
5. The author records a SHA-256 fingerprint of each returned file before comparing anything, so the labels you return cannot be changed afterwards.

**What you will not be told:** which method raised which issue. Please do not try to work it out.

**Credit and use.** Your work will be described in the paper as independent review. You will be named only if you agree. Labels are published without reviewer names (as Reviewer A and Reviewer B).
