# Contributing

Outside code contributions are not accepted yet. This project is released
under a dual licence (AGPL-3.0-or-later and a commercial licence), which
requires the copyright holder to hold the rights to every line. A contributor
licence agreement will be published before contributions are accepted.

Until then:

- Issues are welcome: bug reports, questions about the specification,
  and failing test vectors.
- Please do not open pull requests with code. They will be closed without
  review, and no code from them will be used.
- Report security problems privately to the contact address in COMMERCIAL.md,
  not in a public issue.
